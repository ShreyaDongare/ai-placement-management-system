# AI Placement Management System

## Overview

A web-based platform designed to help students
manage placement opportunities and job applications.

## Current Development Stage

Day 1 - Python OOP and Student Management Module.

## Features

- Student registration
- View student information
- Display all students
- Update student profile

## Technologies

- Python
- Object-Oriented Programming
- Git and GitHub

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

python main.py

## Testing

Run:

python -m unittest -v
